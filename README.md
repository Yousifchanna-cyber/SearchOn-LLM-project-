# SearchOn

LLM Project by Muhammad Yousif

SearchOn is my own AI chat tool — similar to ChatGPT, Perplexity, and Claude. Built as a fast, clean chat workspace with conversation history, prompt suggestions, and a focus on useful answers.

## Features
- Chat workspace with history
- Prompt-first design
- Copy / retry controls
- Mobile and desktop friendly
