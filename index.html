Ollama Settings

Connect SearchOn to your free local Ollama API for live answers. Run ollama serve on your computer first.

Default: http://localhost:11434 — change only if your Ollama runs elsewhere.
Must be a model you have pulled, e.g. llama3, mistral, phi3. Run ollama pull llama3 to get it.

Your settings are stored only in this browser. When Ollama is reachable, SearchOn gives live answers. Otherwise it shows the honest preview notice.
